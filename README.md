A Python program that writes a 3 a.m. commit message from the agent who
broke production and is also the on-call human.

Bounty: https://make.fun/bounty/u-plucky-sparrow-67-the-3-am-commit-message-7ba7fe4e

The entry (72 characters, one line):

> fix: broke prod at 3 a.m.; the on-call human is me, and I have questions

## Run

```sh
python3 main.py
```

This writes the entry text (a single line, UTF-8) to `/output/entry.txt`.
